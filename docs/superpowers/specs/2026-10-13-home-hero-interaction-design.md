# Stopwatch 主页互动优化提案

日期：2026-10-13。状态：用户已批准方案 A，进入实施；设备尚未烧录。

## 用户要求

- 四个角色为大黄蜂、擎天柱、钢铁侠、蜘蛛侠。
- 主页上、下、右滑均随机换角色，取消方向与角色绑定。
- 替换眨眼交互，提升响应速度和互动感。

## 当前代码调查

基线 main@9804867，调查时工作区干净。

- `include/RobotHomeInteraction.h`：四角色共用三次眨眼、总长 1320ms 的时间轴；动画期间点击直接拒绝。
- `src/main.cpp::finishTouchGesture`：中心反应在松手后才启动，按下时没有即时角色反馈。
- `Animation::frameDue` 与 `drawScreen` 各自有 50ms 绘制门限；两者时间基准不同，可能跳过一次应绘制的帧，需要设备测时确认影响。
- `RobotHomeUi.h` / `RobotHomeCharacters.h`：主页即使静止也周期性清屏、解码缩放 JPEG、绘制文本并传输全屏。
- 当前头部点击框为 x=88..378、y=108..319，与视觉头像的全部范围不完全一致。

代码没有给不同角色设置不同眨眼次数。“有的只眨一次”的实际原因尚未真机复现；渲染耗时、跳帧和素材可见度是待测假设，不能宣称已证明。

## 方案比较

| 方案 | 用户体验 | 代价与取舍 |
| --- | --- | --- |
| A 角色技能回应（推荐） | 按下立刻压缩蓄能，松手释放角色特效；再次点击立刻重新回应 | 四角色共用输入和节奏，特效各异；适合桌面常驻 |
| B 触点跟随 | 小范围移动时头像朝手指偏移、倾斜，松手回弹 | 更像宠物；与换角色滑动需要严格仲裁 |
| C 连击小游戏 | 连续点击累积能量、显示连击并释放大招 | 更有游戏感，但增加界面元素和状态，偏离简洁主页 |

## 推荐方案 A

### 统一交互

1. 清醒主页的角色区域触摸按下：立即显示约 3% 的轻压缩与局部蓄能，不等松手。先不给震动，避免普通滑动多震一次。
2. 未达到滑动阈值且 500ms 内在角色区松手：释放约 420ms 技能动画，并给一次 25ms 短震；完整点击视觉过程约 0.5 秒。
3. 新点击可立即中断旧动画并重新进入按压反馈；不排队、不等待上一轮结束。
4. 手势达到现有 52px 滑动阈值：取消点击候选和蓄能。上、下、右只换一次角色，并保留一次既有换角色震动。左滑沿用工作页切换。
5. 500ms 后取消短点击资格，恢复普通头像；保持现有长按电源流程。睡眠首触仅唤醒，离页、睡眠、电源覆盖层均取消角色反馈。

### 四角色效果

| 角色 | 松手反馈 |
| --- | --- |
| 大黄蜂 | 黄色电弧从肩甲/面罩两侧向外短促迸发，头像轻回弹 |
| 擎天柱 | 蓝色能量扫描掠过面罩，左右装甲附近出现短光轨 |
| 钢铁侠 | 掌心炮风格的白蓝能量脉冲从头像前方扩散 |
| 蜘蛛侠 | 白色蛛网从触点向外展开，头像轻微倾斜后回弹 |

四种效果保持同一反馈时长和输入规则。特效在角色区域内完成，顶部连接状态和底部电量不受遮挡。默认静音。

### 随机切换

- 每次上、下、右滑从另外三个角色中随机选择，保证本次一定不同。
- 使用设备随机源，不把方向或时间戳当作随机数；用拒绝采样避免取模偏差。
- 允许 A→B→A，连续重复同方向也有效；一次持续滑动只触发一次。
- 初次进入、重进 Home 仍默认大黄蜂，沿用现有习惯。

### 视觉与性能

- 统一黑底、同一头像比例和视觉重心。保留大黄蜂/擎天柱风格，新增匹配的钢铁侠/蜘蛛侠原创头像。
- 四张头像在进入 Home 时预解码缓存于 PSRAM，动画不逐帧解码 JPEG；分配失败时采用当前角色单张缓存降级。分配失败不得阻止输入或切页。
- 静止时仅状态、电量或覆盖层变化才重绘；动画使用单一时间调度，以实际耗时推进，不用阻塞 delay。
- 触摸按下和有效松手请求优先呈现第一反馈帧；持续动画目标 25–30fps，最终以 C152 实测为准。
- 点击区域按最终头像视觉范围校准；原始触点用于滑动仲裁，避免库内低位移冻结坐标造成误判。

## 验收

- 原生测试覆盖四角色一致时间轴、按下即时状态、连点打断、拖出/滑动取消、唤醒不触发、取消后不重播，以及计时溢出。
- 随机策略测试覆盖每个当前角色、三个方向、可达的三个候选、不可重复当前角色和持续滑动只触发一次。
- 用原生渲染检查四角色按下/释放/结束帧及上下状态安全区。
- C152 实测触摸识别至反馈首帧的延迟，目标 P95≤80ms；按角色分别采集至少 30 次，不把主机测试当作设备延迟证据。体感按下至屏幕变化另用高帧率录像核对。
- 真机验证四角色连点、快速上/下/右随机切换、左滑、睡眠唤醒、电源长按，以及现有工作页和麦克风功能。
- 构建、原生测试、烧录、真机验收分别报告。烧录需在确认当前精确端口和恢复路径后另行批准。
